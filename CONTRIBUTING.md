# Contributing to Filament Manager Pro

Danke für dein Interesse an diesem Projekt! 🎉

## 🐛 Bugs melden

1. Prüfe erst, ob das Problem bereits bekannt ist (Issues)
2. Erstelle ein neues Issue mit:
   - Beschreibung des Problems
   - Schritte zum Reproduzieren
   - Browser und Version
   - Screenshots (falls relevant)

## 💡 Feature Requests

1. Erstelle ein Issue mit dem Label "enhancement"
2. Beschreibe das Feature ausführlich
3. Erkläre den Nutzen für 3D-Drucker-Besitzer

## 🔧 Pull Requests

1. Forke das Repository
2. Erstelle einen Feature-Branch (`git checkout -b feature/AmazingFeature`)
3. Committe deine Änderungen (`git commit -m 'Add some AmazingFeature'`)
4. Pushe zum Branch (`git push origin feature/AmazingFeature`)
5. Öffne einen Pull Request

## 📝 Code-Stil

- HTML: 2 Leerzeichen Einrückung
- JavaScript: ES6+, semikolons
- Keine externen Build-Tools (reine HTML/JS App)
- Mobile-First Design

## 🧪 Testen

Da dies eine reine Frontend-App ist:
1. Teste in verschiedenen Browsern (Chrome, Firefox, Safari)
2. Teste auf mobilen Geräten
3. Stelle sicher, dass Barcode-Scanning funktioniert

## 📄 Lizenz

Mit dem Einreichen eines Pull Requests stimmst du zu, dass deine Beiträge unter der MIT Lizenz veröffentlicht werden.
