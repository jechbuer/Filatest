## [1.0.0] - 2026-02-22

### Added
- 🎉 Erste öffentliche Version
- 📷 Barcode-Scanning mit Kamera
- 📦 Lager-Verwaltung für Filament-Spulen
- 📊 Statistiken und Verbrauchs-Übersicht
- 📱 Mobile-optimierte UI
- 🏷️ QR-Code Etiketten-Druck
- 💾 Lokale Datenspeicherung (IndexedDB)
- 🔍 Filter nach Material (PLA, PETG, ABS)
- 📁 Projekt-Management mit Material-Bedarfsberechnung
- 🌐 Offline-fähige Web-App

### Technisch
- Tailwind CSS für Styling
- Dexie.js für IndexedDB
- html5-qrcode für Barcode-Scanning
- QRCode.js für Etiketten
